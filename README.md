# 一键复制

在思源笔记里给任意一段文字加个复制按钮。

写代码笔记、整理命令、抄配置文件的时候，经常要反复复制同几小段内容。思源自带的复制要么得选中再按快捷键，要么得右键翻菜单。这个插件把这件事缩成一次点击。

## 用法

选中一段文字，右键，菜单底部会多出两项：

- **点击文本直接复制**
- **仅悬停显示复制按钮**

选哪个，这段文字就按哪种方式工作。每段独立设置，互不影响。

### 点击文本直接复制

鼠标移上去，光标变成小手，点一下内容就进剪贴板，旁边弹个图标表示成功。

代价是点击不再把光标放进文字里。想改这段字，得先换成下一种方式。

### 仅悬停显示复制按钮

鼠标移上去，文字右边出现一个复制按钮，点它复制。这段文字照样能点进去编辑。

## 设置

设置 → 集市 → 已下载 → 一键复制 → 设置

- **复制图标 / 成功图标**：点按钮从思源的表情面板里选。也支持 Iconify 名称，格式 `iconify/集合--图标名`，比如 `iconify/coolicons--copy`。
- **常驻复制按钮**：打开后，标记过的文字右边一直显示按钮，不用悬停。
- **点击文本直接复制 / 仅悬停显示复制按钮**：和右键菜单里那两项是同一组开关，关掉之后那种方式就不能用了。

## 关于标记

标记写在文字的 style 里（CSS 变量 `--sycopy`），不改动内容本身，导出的 Markdown 不会多出符号。

思源的行内元素不支持自定义 class 和 data 属性，Lute 解析时会把它们丢掉，所以只能借 style 存。

标记尽量落在原有的行内元素上（行内代码、加粗、斜体、链接、高亮），不额外包一层，这样格式不会被打乱。行内代码是整体，选区只压到其中一半时，会自动把整段代码一起标记。

## 安装

设置 → 集市 → 搜索「一键复制」。

手动装：把整个目录放进 `工作空间/data/plugins/`，重启思源。

## 已知限制

- 常驻按钮最多处理 200 个标记。超过后不再显示（悬停仍然可用），避免长文档卡顿。
- 被标记的文字如果整段删掉重输，标记会丢失，需要重新右键设置。
- 目前只在 macOS 上实测过。
